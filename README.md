## Standardized Documentation Framework

Every investigation in this repository adheres to a standardized SOC report methodology:

1. **Objective**: Scope and goals of the investigation.
2. **Environment**: Technical specs, shell privileges, and target context.
3. **SOC Investigation Log**: Detailed command execution breakdown, observations, and defensive relevance.
4. **Command Evidence**: Sanitized screenshot evidence proving execution and findings.
